# 🌾 AgriSmart

## Overview
AgriSmart is a Generative AI-powered smart agriculture assistant that helps farmers make informed decisions using AI.

## Features
- 🌱 Crop disease diagnosis
- 💧 Irrigation recommendations
- 🌿 Fertilizer suggestions
- 📈 Market price estimation
- 🤖 AI-powered agricultural assistance

## Technologies Used
- Python
- Google Colab
- Groq API
- Hugging Face
- Large Language Models (LLMs)
- Generative AI

## Future Improvements
- Multilingual support
- Mobile application
- Weather integration
- Voice-based AI assistant
